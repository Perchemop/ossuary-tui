# Progress Log

Append-only log of work done, with the evidence for each claim.

## 2026-11-06 — Session 1: discovery, foundation and v0.1.0

**Goal:** take Ossuary from an empty repository to a green v0.1.0 test build.

### Done

- **Discovery** recorded in `docs/project-brief.md`, `docs/scope.md`,
  `docs/inspiration.md`, `docs/product-name.md`,
  `docs/assumptions-and-questions.md`. Four decisions were confirmed with the
  client (terminal app; name Ossuary; interactive art toy; original art + user
  packs) — see `docs/assumptions-and-questions.md`.
- **Foundation**: Cargo workspace, `rust-toolchain.toml`, shared `crash-report`
  and `update-check` crates, `.gitignore`, `deny.toml`.
- **Core** (`crates/ossuary-core`): deterministic RNG, glyph sets, art model,
  config/persistence, the rain engine — with unit tests in every module and a
  headless workflow suite in `tests/workflow.rs`.
- **Shell** (`apps/ossuary`): `crossterm` event loop, painter, key handling,
  crash hook, update check, version + release-notes overlay.
- **CI and release** workflows, PR template, issue forms, scan scripts.
- **Docs**: brand, architecture, capability inventory, parity, development,
  guide-compliance, QC checklist.

### Evidence

- CI `check` run
  [42101993829](https://github.com/Perchemop/ossuary-tui/actions/runs/42101993829):
  **success** — formatting, clippy (no warnings), the headless tests, the
  release build, and the secret and personal-data scans all passed.
- `Cargo.lock` (140 packages) was generated by CI and committed, so no `cargo`
  ran locally (guide §4).
- Merged to `main` as the "Ossuary v0.1.0: first functional build" squash.

### v0.1.0 released

- Tag `v0.1.0` published as a GitHub Release (later **withdrawn** on
  2026-11-06, when the owner moved Ossuary to source-only distribution; the git
  tag remains).
- Release workflow run
  [42103857872](https://github.com/Perchemop/ossuary-tui/actions/runs/42103857872):
  all four targets built (`linux-x86_64`, `linux-arm64`, `macos-arm64`,
  `windows-x86_64`), the release-asset scan passed, and the release was
  published with `SHA256SUMS.txt`. The first attempt failed only because the
  macOS runner could not be acquired (GitHub capacity); a re-run succeeded.
- **Smoke test of the published artefact** (this ARM machine): the
  `ossuary-linux-arm64` binary prints `ossuary 0.1.0` for `--version`, prints
  help, and under a pseudo-terminal enters the alternate screen, hides the
  cursor and paints falling glyphs — 37 KB of frame output in 2.5 s.
- Token ledger recorded `0.1.0` (no per-release token instrumentation yet; the
  figure is recorded honestly as 0 rather than invented).

### Next

- A hands-on look at the macOS and Windows artefacts on those systems.

**Goal (owner directive):** "I only want this app available as a tui, not

### Done

  stack is linked in. Ossuary is now fully offline.
- Removed the release-only helper scripts.
- Rewrote the README around installing/running from source in a terminal.
- Updated scope, roadmap, architecture, capability inventory, parity,
  guide-compliance, ATTRIBUTION, SECURITY, CHANGELOG and DECISIONS.
