# Vision

## What Ossuary is

A small, free, offline terminal application that turns idle screen real estate
into a quiet, moving piece of typographic art: falling characters that
periodically gather into hand-typed pictures and then let them go.

## What it is not

- Not a windowed application; it lives where it belongs, in the terminal.
- Not a katakana clone; the visual language is sparse punctuation, monochrome
  and whole pictures.
- Not a platform; there is no account, no cloud, no telemetry.

## Principles

1. **Local and free.** No network required, no cost, permissive licence.
2. **Honest.** Claims in the README and release notes match what the code does.
3. **Small.** A tiny dependency footprint and a small, readable codebase.
4. **Original.** Every piece of art and every line of code is ours.
5. **Testable.** The interesting behaviour lives in a headless core, so CI can
   prove it works.

## Long-term direction

Grow the pool of original art, add tasteful variation (rotation modes, subtle
colour drift within the monochrome ramp), and make updating effortless — without
ever growing the core into something heavier than a screensaver should be.
