# Product Name — Locked

**Name**: **Ossuary**

**Tagline**: *A terminal ASCII-art rain, hand-typed.*

## Origin

- **Decision (2026-11-06)**: the name `Ossuary` was chosen during discovery
  (guide §0, question E19: invent an original name) and is locked. It was not
  taken from any existing product.
- An *ossuary* is a resting place for bones — a natural fit for a rain of
  hand-typed skulls and bones, and short, sayable and easy to spell.

## Where the name is used

- Crate/package names: `ossuary`, `ossuary-core`
- Binary: `ossuary`
- Window/terminal title and status line: `Ossuary`
- Theme file: `theme.json` inside the per-user config directory
  (`~/.config/ossuary/` on Linux)
- Release artefacts: `ossuary-linux-x86_64`, `ossuary-macos-arm64`,
  `ossuary-windows-x86_64`, …

## Rule

Any rename requires a `DECISIONS.md` entry and a traceability update; the name
above is the single source of truth for branding.
