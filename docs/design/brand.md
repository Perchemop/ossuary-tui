# Brand

Original visual identity for Ossuary. No third party's logo, icon, font or trade
dress is used (guide §10, §II.19.2).

## Meaning

The mark is a minimal skull reduced to the fewest strokes that still read as one:
a rounded cranium, two eye sockets and a short nasal notch. It nods to the
hand-typed skull art the app shows, without copying anyone's drawing. The
wordmark is the plain word "Ossuary" set in the terminal's own monospace font.

## Palette

Ossuary is deliberately monochrome. Brightness is a ramp, not hue:

| Band | Meaning | Terminal colour |
|------|---------|-----------------|
| 0 | empty | default background |
| 1 | dim tail | dark grey |
| 2 | mid trail | grey |
| 3 | bright head | white |

An alternate retro-green palette maps the same bands to dark green / green /
light green, and is toggled with the `m` key.

## Type

The app uses the terminal's configured monospace font — the honest choice for a
TUI, and the one the user has chosen to look at. No font is embedded or shipped.

## Voice and tone

Plain, dry and a little playful ("a terminal ASCII-art rain, hand-typed"). No
jargon in user-facing text; inclusive wording throughout. The same voice is used
in the README, release notes and issue templates.

## Assets

- `assets/logo.svg` — the mark.
- `assets/icons/ossuary.svg` — the square app icon built from the mark.
