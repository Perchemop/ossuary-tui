# Branding Kit

Original identity for Ossuary (guide §10). See `docs/design/brand.md` for the
reasoning; this file is the practical kit.

## Mark

`assets/logo.svg` — a minimal skull: rounded cranium, two eye sockets, a short
nasal notch. Monochrome (currentColour / black). Usable on light or dark.

## Icon

`assets/icons/ossuary.svg` — the mark inside a rounded square, drawn as text on
a dark field, evoking a terminal cell.

## Colours

| Token | Hex | Use |
|-------|-----|-----|
| `bg` | `#0B0B0B` | near-black background |
| `dim` | `#4D4D4D` | dim tail band |
| `mid` | `#9A9A9A` | mid trail band |
| `bright` | `#F2F2F2` | bright head band |
| `green` | `#22C55E` | optional retro-green accent |

## Type

No embedded font. The application uses the terminal's monospace font. The
wordmark, where a font is needed (README, release notes), is the plain word
"Ossuary".

## Voice

Plain, dry, a little playful. No jargon. Inclusive wording ("they" for a single
person). Used consistently in README, release notes and issue templates.
